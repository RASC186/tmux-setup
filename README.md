# tmux Installer

This project contains scripts to install and uninstall tmux in a Debian-based Linux distribution.

## Prerequisites

To use the installer script, **git** will be necessary. Run the following command to install it:

```
apt install git
```

## Instructions

To install tmux, run 

```
./install
```

To uninstall tmux and remove all configuration files, run

```
./uninstall
```
